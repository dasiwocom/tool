什么时候需要把 HTML 转成 Markdown

从网页里复制带格式的文字，粘进编辑器常是一堆 <div>、<span> 和行内样式，又乱又难管。博客搬家、整理他人页面、把富文本邮件转成文本文档时尤其头疼。用 HTML 转 Markdown 工具，粘贴一段 HTML，瞬间得到干净的 Markdown。

转换规则

  • 标题与段落：<h1>–<h6>、<p> 自动映射为 Markdown 的 # 标题与段落。
  • 代码块：<pre><code> 转成带语言标注的围栏代码块，方便语法高亮。
  • 表格：直接生成 GFM 管道式表格，在 GitHub、Typora 等主流 Markdown 里都能正常渲染。
  • 链接、图片、列表、加粗斜体：全部转换为对应的 Markdown 语法，行内样式会被丢弃，输出是纯文本源码。

使用小技巧

不确定流程？点“示例”按钮，工具会填入一段测试 HTML，转换后对照输入输出，很快就能看懂映射关系。转换结果支持一键复制，可直接粘回编辑器。整个过程在浏览器本地进行，粘贴的任何内容都不会上传。
