What the keyboard test tool does

Checking out a new keyboard, hunting a dead key, or verifying that simultaneous presses register correctly — the Keyboard Test tool figures it out in seconds:

  • Keys light up live — press any key and the matching key on the virtual keyboard highlights immediately.
  • Rollover detection — press several keys at once and watch whether each one registers correctly.
  • Hold state — see which keys are held down and whether auto-repeat is firing.
  • Raw events — the event log shows key, code, keyCode, location, and modifiers for every press, handy for debugging scripts or remapping keys.

How to read the results

If a key does not light up when pressed, it is not being recognized — possibly a faulty key, a driver issue, or a layout mismatch. Gamers care most about rollover: hold Shift and press several letter keys; if some combinations miss, the keyboard has key conflicts.

Every log entry carries the full parameter set (key value, code, location, repeat flag), and the ✕ button clears the log so you can inspect sections one by one.

Notes

The tool reads the browser's standard key events — no drivers or software to install, works across platforms. Everything runs locally, and your input is never recorded or uploaded.
