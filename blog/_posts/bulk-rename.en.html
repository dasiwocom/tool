When you need bulk renaming

A batch of photos needs a shared prefix, exported assets need sequential numbers, or legacy files must match a naming convention — renaming by hand is slow and error-prone. Generate the mapping first with rules, then apply it.

How the tool works

Open the bulk rename tool:

  1. Paste file names — one per line, listing everything to rename.
  2. Pick a rule — prefix + name + suffix keeps the original name and adds around it; prefix + number + suffix renumbers from scratch (extensions are kept automatically).
  3. Set start and padding — choose the starting number and zero padding, e.g. begin at 001.
  4. Generate — get the old-to-new mapping and copy any new name with one click.

A tip

Pad to the same width as your file count (three digits for 100 files) so sorting stays clean. Review the generated mapping in your file manager before actually applying the renames.
