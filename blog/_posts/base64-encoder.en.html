What is Base64?

Base64 is an encoding that translates arbitrary binary data into 64 printable characters. It is not about secrecy — it exists so data can travel safely through text-only channels: email, JSON, URLs, and small images embedded in HTML.

What this tool does

Open the Base64 encoder: paste any text to encode, paste a Base64 string to decode, and copy the result in one click. Two alphabets are available:

  • Standard mode — the common alphabet, including + / =.
  • URL-safe mode — swaps + and / for - and _ and drops the = padding, so the result survives links and JWTs without escaping.

Key facts

  • Base64 is not encryption — anyone can decode it with the same tool. Encrypt first, then encode.
  • Size overhead — output is about 4/3 the original; weigh that before shipping large files.
  • Decode failures — usually stray spaces, line breaks, or the wrong alphabet.

Typical uses

Inline icons via data URIs, JWT segments, and squeezing binary fields into text protocols — URL-safe mode is the safer choice in all of these. Everything runs locally.
