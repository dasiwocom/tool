Making a GIF from stills

Memes, presentation slideshows, action replays, or a set of photos animated simply — merging still frames into an animated GIF is the most direct way to do it.

How the tool works

Open the GIF maker:

  1. Add multiple images — queue the frames in play order.
  2. Set the output size — choose the width to balance file size and sharpness.
  3. Set the frame delay — milliseconds per frame, which sets the animation speed.
  4. Generate and download — merge into an animated GIF in one click.

A tip

Pre-crop frames to identical dimensions for a tidy animation; larger delays play slower. Color-rich scenes make GIFs balloon in size, so compressing the frames first helps. Everything is generated locally in your browser.
