强密码生成器：长度、字符集自由定制

Strong Password Generator with Custom Character Sets

ToolBox Blog · 2026-09-19

怎么生成强密码

打开 密码生成器，四步得到符合要求的随机密码：

  1. 调长度：拖动滑块设置密码长度，越长越难被暴力破解。
  2. 选字符集：按需勾选大写字母、小写字母、数字或符号。
  3. 生成：点击生成，得到一串完全随机的组合。
  4. 复制：复制后直接用在你想要的平台。

安全建议

  • 长度优先：密码强度主要由长度决定，推荐至少 14–16 位。
  • 每个账号单独一个密码：不要复用，配合密码管理器集中保存。
  • 尽量开启两步验证：密码再强，也挡不住勾选“记住我”的设备被单独窃取。

隐私

密码完全在浏览器本地生成，不经过任何服务器，关闭页面即消失。复制的密码请妥善保管，避免明文存入云端笔记。

Generating a strong password

Open the password generator and build exactly the password a site needs, in four steps:

  1. Set the length — drag the slider; longer means far harder to brute-force.
  2. Choose the character set — tick uppercase, lowercase, digits, or symbols as required.
  3. Generate — produce a fully random combination.
  4. Copy — use it wherever you like.

Security tips

  • Length first — strength comes mostly from length; aim for at least 14–16 characters.
  • One password per account — never reuse, and keep them in a password manager.
  • Turn on two-factor authentication — even strong passwords cannot protect a compromised device session.

Privacy

Passwords are generated entirely in your browser — nothing touches a server and nothing is stored after you close the tab. Copied passwords should be kept safe and never pasted into plain-text cloud notes.
